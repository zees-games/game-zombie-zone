# Recorded sounds (`real/`)

Every file is CC0 (public domain dedication) except `hurt_1`, which is CC-BY 3.0 (credit Vinrax); the licence was read on each source page (OpenGameArt, Freesound) before download. Each file is cut, trimmed, high-passed and loudness-normalised (about -18 LUFS) and encoded to ogg by `tools/build_real_sounds.py`. Nobody has listened to these yet; `tools/sound_compare.tscn` plays old against new.

Where a Freesound sound was fetched, the high-quality preview (mp3) was the source.
